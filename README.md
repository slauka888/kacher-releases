# Kacher — релизы

Здесь публикуются **только готовые сборки**: установщик, контрольные суммы и заметки
к выпуску. Исходный код приложения закрыт и в этом репозитории его нет.

## Что скачивать

| Файл | Что это |
|---|---|
| `KacherSetup-<версия>.exe` | установщик для Windows 10/11 (64-бит) |
| `SHA256SUMS.txt` | контрольные суммы файлов релиза |
| `KacherExtension.zip` | браузерное расширение (необязательно, ставится вручную) |

## Как проверить файл

Скачанный установщик стоит сверить с суммой из `SHA256SUMS.txt` — так видно, что файл
доехал целиком и не был подменён:

```powershell
Get-FileHash .\KacherSetup-2.2.0.exe -Algorithm SHA256
```

Полученное значение должно совпасть со строкой из `SHA256SUMS.txt` для этого файла.

## Обновления

Приложение само сообщает о новой версии и предлагает скачать установщик со страницы
релиза. Тихая установка без ведома пользователя не выполняется.

## О подписи

Установщик **не подписан** сертификатом code signing, поэтому Windows может показать
предупреждение «Windows protected your PC» при первом запуске (SmartScreen). Это
ожидаемо; целостность файла проверяйте по SHA256.

## Первый запуск

Установщик ставит программу в `%LOCALAPPDATA%\Programs\Kacher` и создаёт ярлык.
Компоненты (FFmpeg, yt-dlp, Node.js) докачиваются мастером первого запуска — интернет
нужен только для этого шага. Настройки: `%APPDATA%\Kacher`, логи и отчёты о сбоях —
там же в `logs`.
